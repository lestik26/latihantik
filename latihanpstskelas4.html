MATERI PEMBELAJARAN TIK KELAS 4 SD

Topik: Menjadi Ahli Dokumen Digital dengan Google Docs

🎯 Tujuan Pembelajaran:
  1. Memahami konsep dasar aplikasi pengolah kata berbasis cloud (Google Docs).
  2. Mengenal penyusunan Data Sederhana pada dokumen digital.
  3. Menguasai 3 elemen formatting dasar: Font, Size, dan Style.
  4. Menggunakan fitur pembuatan daftar: Bullet List dan Numbering.
  5. Memahami penggunaan warna teks (Text Color) dan warna latar (Highlight Color).

1. Mengenal Google Docs & Data Sederhana

Google Docs adalah aplikasi pengolah kata berbasis web (online) yang dikembangkan oleh Google. Salah satu kelebihan utamanya adalah dokumen kita akan tersimpan secara otomatis di penyimpanan awan (Google Drive) tanpa khawatir hilang saat mati lampu.

Data Sederhana: Kumpulan informasi atau keterangan tentang sesuatu di sekitar kita yang disusun secara rapi dan mudah dibaca (contoh: daftar nama siswa, daftar belanjaan, jadwal piket kelas).

2. Memformat Teks (Font, Size, & Style)

Agar teks dokumen kita terlihat rapi dan menarik, kita perlu mengatur 3 elemen format dasar:

  • Font (Jenis Huruf): Menentukan bentuk karakter teks (contoh: Arial, Georgia, Caveat).
  • Font Size (Ukuran Huruf): Mengatur besar kecilnya huruf pada tulisan.
  • Text Style (Gaya Teks): Menandai atau menonjolkan poin penting.
Gaya Teks (Style) Ikon / Tombol Pintasan Keyboard (Shortcut) Kegunaan Utama
Bold (Tebal) B Ctrl + B Menebalkan judul atau kata penting.
Italic (Miring) I Ctrl + I Memiringkan istilah asing atau kata penekanan.
Underline (Garis Bawah) U Ctrl + U Memberi garis bawah pada kata/poin penting.

3. Membuat Daftar (Bullet List vs Numbering)

Untuk merapikan data sederhana berupa susunan kata atau kalimat, kita dapat menggunakan dua jenis daftar:

  • Bullet List (Daftar Simbol): Menggunakan simbol seperti titik tebal (•) atau kotak (■). Digunakan jika urutan data tidak terlalu penting (contoh: daftar alat tulis, daftar belanja).
  • Numbering (Penomoran): Menggunakan angka (1, 2, 3) atau huruf (A, B, C) secara otomatis. Digunakan jika urutan data sangat penting (contoh: nomor absen siswa, langkah-langkah resep masakan).

4. Menggunakan Warna pada Dokumen

Pemberian warna membuat dokumen tidak membosankan dan membantu pembaca menemukan informasi penting dengan cepat:

  • Text Color (Warna Teks): Mengubah warna tulisan atau huruf itu sendiri (ikon huruf A bergaris warna).
  • Highlight Color (Warna Stabilo): Memberikan warna pada latar belakang teks layaknya menggunakan spidol stabilo.
💡 Tips Memilih Warna:
Pilihlah warna yang kontras dengan latar belakang agar tulisan tetap jelas terbaca, tidak berlebihan, dan konsisten!

Mengingat Kembali: Apa Itu Internet? 🌐

Internet adalah jaringan dari banyak jaringan komputer di seluruh dunia.

  • Menghubungkan perangkat dan manusia di mana pun
  • Dipakai untuk mencari informasi, belajar, dan berkomunikasi
Hari ini: kita ikuti perjalanan data di dalam internet!

Empat Pemain Utama 🧩

🧒Web User
Pengguna yang memakai perangkat (HP, laptop) untuk mengakses internet
🏢ISP (Internet Service Provider)
Penyedia layanan internet
🌐Internet
Jaringan global penghubung
🖥️Web Server (peladen web)
Penyimpan data web
Alur: Web User ➜ ISP ➜ Internet ➜ Web Server. Permintaan data selalu dimulai dari Web User. Tanpa ISP, perangkat sulit terhubung ke internet.

Mengapa Data Cepat Sampai? ⚡

  • Data bergerak lewat kabel dan sinyal dengan sangat cepat
  • Banyak perangkat jaringan bekerja sama
  • Router mengarahkan jalur data
  • DNS mengubah nama situs menjadi alamat tujuan
  • Server mengirim data yang diminta
  • Kabel bawah laut membawa data antar benua

Jika Internet Bermasalah 🔧

Halaman tidak muncul atau video tersendat? Penyebabnya bisa:
  • Gangguan di ISP
  • Gangguan di web server
  • Sambungan atau kecepatan internet lemah
  • Perangkat kurang mendukung
Jika tanpa ISP:
  • Perangkat sulit terhubung ke internet
  • Permintaan data tidak sampai ke web server

ISP adalah penghubung antara kita dan internet.
